# 数据说明

本目录存放食材、食谱、单位换算、烹调油和疾病关系。营养数值、GI 和禁忌关系必须有出处。核对完成前，`source` 写 `待核对`，不要填没有依据的数字。

## 目录

| 路径 | 内容 | 是否进入 Git |
|---|---|---|
| `raw/` | 本地原始文件。指南 PDF、整本《中国食物成分表》放这里 | PDF 不进入 Git |
| `processed/` | 清洗后的 CSV / JSON | 只提交来源和许可证清楚的文件 |

每个入库的数据文件在本说明中追加一行：文件名、来源链接、获取日期、许可证。
